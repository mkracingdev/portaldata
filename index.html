Tentang Portal Master Data

Satu pintu ke lima web kerja perusahaan. Datanya saling tersambung lewat Google Sheets. Saat sebuah web dibuka, menu atas bersembunyi agar layar lega. Arahkan kursor atau ketuk garis tipis di paling atas untuk memunculkannya lagi.

K7Q2MX

Kode akses per web. Setiap web punya daftar akses sendiri. Anda hanya bisa masuk ke web yang mencantumkan nama Anda; umumnya kodenya sama di semua web yang boleh Anda buka. Kalau sebuah web menolak padahal kode benar, minta admin menambahkan Anda di daftar akses web itu.

Lima web

R&D HUB

Ide, project, timeline, workspace (GMV, Harga EQU, task, isu), material, Terbit SKU, laporan bulanan.

Inventory Material

Stok Gudang & Atas, IN/OUT/NG/Pindah, stock opname, persiapan produksi & bahan curah, pembelian, PO, supplier, retur, material impor.

PRODUCTION HUB

Rencana, WO, jadwal & penugasan, kehadiran, input hasil, NG & komplain, Stok Pelita, pengiriman, laporan nilai.

DEPLOYMENT HUB

Perintah pimpinan sampai diverifikasi, pengingat tugas jabatan, sasaran & KPI divisi, rapat & notulen, laporan per divisi/PIC.

Marketing Hub

Omzet Shopee/TikTok/Offline, iklan, live, konten, Strategic Radar, KPI SDM, report harian WA.

Bagaimana datanya tersambung

Marketing Hub memakai file MARKETING MANAGEMENT sendiri dan membaca stok produk dari Inventory untuk laporan penjualan dan cek stok marketplace.
